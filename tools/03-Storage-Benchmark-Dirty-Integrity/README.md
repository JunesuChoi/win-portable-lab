# Storage benchmark, dirty and integrity / 저장장치 성능, 더티 및 무결성

CrystalDiskMark와 DiskSpd는 제한된 시험 파일 성능, 나래온 더티 테스트는 넓은 공간을 소비하는 지속 쓰기, H2testw는 전체 쓰기·읽기 검증, ValiDrive는 USB 용량 스폿체크에 사용합니다. SD Memory Card Formatter는 SD/SDHC/SDXC 카드의 전용 포맷 도구이며, 선택한 카드의 데이터가 삭제되므로 자동 실행하지 않습니다. 쓰기 전 백업과 대상 드라이브 재확인이 필수입니다.

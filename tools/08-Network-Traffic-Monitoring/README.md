# Network traffic monitoring / 네트워크 트래픽 모니터링

TrafficMonitor Lite is kept here as an official portable GitHub release. It provides taskbar or floating-window network throughput plus CPU, RAM, GPU and disk utilization.

TrafficMonitor Lite는 공식 GitHub 포터블 릴리스를 사용합니다. 작업 표시줄 또는 플로팅 창에서 네트워크 속도와 CPU, RAM, GPU, 디스크 사용률을 확인합니다.

Temperature monitoring remains assigned to LibreHardwareMonitor/HWiNFO because TrafficMonitor upstream is retiring the standard edition's built-in temperature backend in favor of a separate plugin.

# GPU 종류별 점검과 DDU 사용

## 공통 점검

GPU 모델, 노트북/OEM 여부, 드라이버 버전·날짜, 유휴 온도·클럭, 부하 온도·클럭, 전력 제한과 기존 오버클럭을 기록합니다. GPU-Z와 HWiNFO로 기준선을 수집합니다.

| GPU | 기본 경로 |
| --- | --- |
| NVIDIA | 기존 오버클럭을 초기화하고 공식 또는 OEM 드라이버로 검사 |
| AMD Radeon | Adrenalin 기본값에서 검사. 제거 실패 시 AMD Cleanup Utility 또는 DDU 검토 |
| Intel Arc/iGPU | OEM 사용자 지정과 Intel 클린 설치 경로를 먼저 확인 |
| 노트북 하이브리드 | iGPU/dGPU 둘 다 기록하고 OEM 드라이버 의존성을 확인 |

## DDU를 쓰는 경우

정상적인 매 업데이트마다 쓰지 않습니다. 일반 제거 실패, 드라이버 설치 반복 실패, GPU 제조사 변경 때만 검토합니다.

1. BitLocker 복구 키와 Windows 로그인 암호를 확인합니다.
2. 교체 드라이버를 미리 받습니다.
3. 시스템 복원 또는 백업을 준비합니다.
4. 네트워크를 끊고 로컬 디스크에서 실행합니다.
5. 안전 모드를 우선 사용합니다.
6. 제거 후 준비한 드라이버를 설치하고 네트워크를 복구합니다.

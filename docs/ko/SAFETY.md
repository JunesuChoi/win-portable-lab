# 안전 원칙

- 권장 설정 파일은 `applyAllowed: false`이며 자동 적용할 수 없습니다.
- 물리 디스크·파티션 직접 쓰기 벤치마크를 금지합니다.
- DDU, 드라이버 삭제, 팬 제어, CPU/RAM 튜닝은 명시적 위험 확인이 필요합니다.
- 계산 오류, 메모리 오류, WHEA, 멈춤, 재부팅, BSOD, 데이터 손상은 모두 즉시 중단 조건입니다.
- 한 번의 통과로 완전한 안정성을 선언하지 않습니다.
- 정확한 모델을 확인할 수 없으면 전압·배수·온도 상한을 추정하지 않습니다.

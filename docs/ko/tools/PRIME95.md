# Prime95 상세 사용법

CPU 계산 안정성을 검사합니다. 오버클럭이나 전압을 조정한 뒤 계산 오류가 나는지 확인하는 데 씁니다. 발열이 매우 큰 도구이므로 온도 감시 없이 실행하지 않습니다.

실행 ID는 `prime95`이고 위험도는 고부하입니다.

## 실행 전 확인

1. HWiNFO를 먼저 띄워 CPU 패키지 온도, 코어별 온도, VRM 온도, 전력을 봅니다.
2. 해당 CPU 모델의 공식 최대 온도를 확인합니다. 이 값은 모델마다 다르므로 자동으로 정하지 않습니다.
3. 저장하지 않은 작업을 닫습니다.

## 시작 시 선택

실행하면 GIMPS 소수 찾기 프로젝트 참여 여부를 묻습니다. 반드시 `Just Stress Testing`을 선택합니다. 계정 정보를 입력하면 네트워크로 작업을 받아옵니다. 이 프로젝트는 검사 목적만 사용합니다.

## 테스트 종류

| 종류 | 성격 | 권장 상황 |
|---|---|---|
| Smallest FFTs | 캐시 안에서 반복. 발열 최대, 메모리 영향 최소 | CPU 코어와 전압 단독 검증 |
| Small FFTs | 위와 유사하나 약간 넓음 | 코어 안정성 표준 검사 |
| Large FFTs | 메모리 컨트롤러까지 부하 | CPU와 RAM 조합 검증 |
| Blend | 메모리를 크게 사용하며 혼합 | 종합 검증. 기본 권장 |
| Custom | FFT 범위와 메모리량 직접 지정 | 특정 구간 재현 |

## AVX 관련 주의

최신 버전은 AVX와 AVX-512 명령을 사용합니다. AVX-512가 동작하는 CPU에서는 실사용에서 결코 나오지 않는 발열이 발생합니다. 목적에 따라 나눕니다.

- 실사용 안정성 확인이 목적이라면 `Options` 메뉴의 CPU 설정에서 AVX-512를 끄고 검사합니다.
- 최악 조건 여유를 보려면 켠 상태로 짧게 확인합니다. 이때 온도가 한계에 닿으면 즉시 중단합니다.

AVX-512를 켠 상태에서 온도 때문에 실패한 것을 계산 불안정으로 오판하지 않도록 구분해 기록합니다.

## 판정 기준

| 목적 | 권장 시간 | 통과 조건 |
|---|---|---|
| 빠른 선별 | Small FFTs 10분 | 오류 0, 워커 중단 없음 |
| 기본 검증 | Blend 30분 | 오류 0 |
| 상용 안정성 | Blend 60분 이상 | 오류 0, 온도 안정 |

워커 창에 `FATAL ERROR` 또는 `rounding was` 같은 문구가 나오면 실패입니다. 하나의 워커만 멈춰도 실패로 봅니다. 결과는 프로그램 폴더의 `results.txt`에 기록됩니다.

## 즉시 중단 조건

- CPU 온도가 모델 공식 한계에 접근할 때
- 워커에 오류가 표시되거나 워커가 멈출 때
- 시스템이 멈추거나 재부팅될 때
- 이벤트 로그에 WHEA 오류가 기록될 때
- VRM 온도가 급격히 오를 때

## 다른 도구와의 관계

Prime95는 CPU 계산 안정성에 특화되어 있습니다. 메모리 오류는 TestMem5와 HCI MemTest가 더 잘 찾습니다. 전원 공급과 복합 부하는 OCCT로 확인합니다. 세 도구는 서로를 대체하지 않습니다.

```powershell
.\scripts\Open-PortableTool.ps1 -Root . -Id prime95 -AcknowledgeRisk -Language ko
```

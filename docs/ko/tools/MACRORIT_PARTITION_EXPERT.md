# Macrorit Partition Expert 상세 사용법

파티션을 생성, 삭제, 포맷하고 크기를 조정하는 무료 포터블 도구입니다. MiniTool처럼 적용 단계에서 결제 창이 뜨지 않고, 무료 등급에서 리사이즈와 MBR/GPT 변환(시스템 디스크 제외)까지 실제로 동작하는 것이 이 도구를 채택한 이유입니다.

실행 ID는 `macrorit-partition-expert`이고 위험도는 파티션 쓰기(최상위)입니다.

## 가장 중요한 원칙

**작업 대상 디스크를 두 번 확인하십시오.** 파티션 작업은 되돌리기 어렵고, 잘못된 디스크에 적용하면 데이터가 사라집니다.

1. 작업 전 중요한 데이터는 다른 물리 디스크로 백업합니다.
2. 여러 디스크가 달린 PC에서는 디스크 번호와 용량으로 대상을 재확인합니다. Windows 디스크 관리(diskmgmt.msc)의 번호와 비교하면 실수를 줄일 수 있습니다.
3. 이 프로젝트는 프로그램 창만 엽니다. 작업은 항상 사용자가 직접 선택하고 적용합니다.

## 무료 등급에서 되는 것

| 작업 | 무료 여부 |
|---|---|
| 파티션 생성·삭제·포맷 | 무료 |
| 리사이즈·이동(확장 포함) | 무료 |
| 비시스템 디스크 MBR↔GPT 변환 | 무료 |
| 시스템 디스크 MBR→GPT 변환, OS 마이그레이션 | 유료 (이 프로젝트 범위 아님) |

## 권장 절차

1. 관리자 권한으로 실행합니다. 관리자 권한이 없으면 디스크 목록이 비어 보입니다.
2. 상단 디스크 선택기에서 대상 디스크를 확인합니다.
3. 작업을 지정합니다. 실제 쓰기는 하단 Commit/Apply를 눌러야 시작됩니다.
4. 적용 전에 작업 목록을 다시 읽고 대상이 맞는지 확인합니다.
5. 적용 중에는 프로그램을 닫거나 전원을 끄지 않습니다.
6. 완료 후 Windows 디스크 관리에서 결과가 계획과 일치하는지 확인합니다.

## 절대 하지 말 것

시스템 파티션 리사이즈를 배터리로만 동작하는 노트북에서 진행하지 않습니다. 중간에 전원이 끊기면 부팅이 깨질 수 있습니다. 데이터가 담긴 디스크를 백업 없이 포맷하지 않습니다.

## 다른 도구와의 관계

이동식 미디어 단순 포맷은 SD Memory Card Formatter가 더 안전합니다. MBR/GPT 복구, 배드섹터 검사처럼 고급 작업은 DiskGenius가 담당합니다. 파티션 작업 후에는 CrystalDiskInfo로 디스크 상태를 다시 확인하는 편이 좋습니다.

```powershell
.\scripts\Open-PortableTool.ps1 -Root . -Id macrorit-partition-expert -AcknowledgeRisk -Language ko
```

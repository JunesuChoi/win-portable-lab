# 나래온 더티 테스트 상세 사용법

SSD의 빈 공간을 채워가며 쓰기 속도를 기록합니다. 카탈로그 성능은 SLC 캐시가 살아 있는 초반 구간만 보여주는데, 이 도구는 캐시가 소진된 뒤 실제 속도가 어디까지 떨어지는지 보여줍니다. 대용량 복사 중 속도가 급락하는 증상의 근거를 만드는 데 씁니다.

실행 ID는 `naraeon-dirty-test`이고 위험도는 빈 공간 전체를 채우는 고위험 쓰기입니다.

## 실행 전 반드시 확인

이 검사는 SSD 수명(TBW)을 소모하고 빈 공간을 가득 채웁니다.

1. 대상 드라이브에 중요한 데이터가 없는지 확인합니다. 백업이 있어도 대상 문자를 다시 확인합니다.
2. 운영체제 드라이브에는 실행하지 않습니다. 공간이 가득 차면 Windows가 불안정해집니다.
3. CrystalDiskInfo로 SMART 상태와 온도를 먼저 확인합니다. 이미 경고 상태면 실행하지 않습니다.
4. 예상 쓰기량을 기록합니다. 빈 공간 크기만큼 쓰입니다.

## 그래프 해석

결과 그래프에서 최고 속도가 아니라 형태를 봅니다.

| 그래프 형태 | 해석 |
|---|---|
| 초반 높은 속도 후 완만한 하강 | 정상. SLC 캐시 소진 후 TLC/QLC 직접 쓰기 속도 |
| 급격한 계단식 하락 | 캐시 정책 전환. 모델 특성이면 정상 |
| 특정 지점에서 극단적 저하 후 회복 없음 | 주의. 컨트롤러 또는 낸드 문제 가능 |
| 톱니처럼 심한 진동 | 주의. 발열로 인한 스로틀링 의심 |
| 중간에 0에 가까운 구간 | 문제. I/O 정지 발생 |

온도와 함께 보는 것이 중요합니다. 속도 저하가 발열 때문인지 낸드 특성 때문인지 구분해야 합니다. HWiNFO나 CrystalDiskInfo로 검사 중 온도를 함께 기록합니다.

## 판정 기준

| 확인 항목 | 정상 |
|---|---|
| 캐시 이후 최저 속도 | 모델 사양의 직접 쓰기 속도 수준 유지 |
| I/O 정지 구간 | 없음 |
| 검사 중 온도 | 스로틀링 임계 미달 |
| 검사 후 SMART | 재할당 섹터, 미디어 오류 증가 없음 |
| 이벤트 로그 | 디스크·컨트롤러 오류 없음 |

검사 후 SMART를 다시 확인하는 단계를 건너뛰지 않습니다. 쓰기 부하 직후에 드러나는 문제가 있습니다.

## 즉시 중단 조건

- 드라이브 온도가 제조사 한계에 접근할 때
- 속도가 0에 가까워지고 회복되지 않을 때
- 장치가 목록에서 사라지거나 재연결될 때
- 이벤트 로그에 디스크 오류가 기록될 때
- SMART 경고가 발생할 때

## 검사 후 정리

검사가 만든 파일을 삭제해 공간을 회복합니다. WizTree로 남은 테스트 파일이 없는지 확인하면 확실합니다. 그다음 CrystalDiskInfo로 SMART를 재확인합니다.

## 다른 도구와의 관계

성능 기준선만 필요하면 CrystalDiskMark가 훨씬 짧고 안전합니다. 용량 허위 표기나 데이터 무결성 확인은 H2testw가 목적에 맞습니다. 더티 테스트는 지속 쓰기 특성을 볼 때만 씁니다.

```powershell
.\scripts\Open-PortableTool.ps1 -Root . -Id naraeon-dirty-test -AcknowledgeRisk -Language ko
```

# BatteryInfoView 상세 사용법

노트북 배터리의 실제 남은 용량과 마모 정도를 확인합니다. Windows 기본 화면은 남은 퍼센트만 보여주지만, 이 도구는 설계 용량 대비 현재 완충 용량과 충전 사이클을 보여줍니다. 배터리 교체 시점 판단에 씁니다.

실행 ID는 `batteryinfoview`이고 읽기 전용입니다.

## 주요 항목

| 항목 | 의미 | 판단 |
|---|---|---|
| Designed Capacity | 제조 시 설계 용량 | 기준값 |
| Full Charged Capacity | 현재 완충 시 실제 용량 | 설계 용량과 비교 |
| Battery Wear Level | 마모율 | 100%에서 멀어질수록 노화 |
| Charge/Discharge Cycles | 충방전 사이클 수 | 제조사 보증 사이클과 비교 |
| Voltage | 현재 전압 | 셀 상태 참고 |
| Charge/Discharge Rate | 현재 충전 또는 방전 속도 | 실사용 소비 전력 확인 |
| Power State | 충전 중, 방전 중, AC 연결 | 현재 상태 |

## 마모율 판단 기준

| 마모율 | 해석 |
|---|---|
| 90% 이상 | 양호 |
| 80에서 90% | 정상 노화 범위 |
| 60에서 80% | 사용 시간 체감 감소. 사용 패턴에 따라 교체 검토 |
| 60% 미만 | 교체 권장 |

사이클 수도 함께 봅니다. 일반 노트북 배터리는 300에서 500 사이클을 보증 기준으로 삼는 경우가 많습니다. 사이클이 적은데 마모율이 크게 떨어졌다면 고온 환경이나 상시 완충 보관이 원인일 수 있습니다.

## 사용 순서

1. AC 어댑터를 뺀 상태로 실행하면 방전 속도를 볼 수 있습니다.
2. 항목을 읽고 필요하면 `File` 메뉴에서 보고서로 저장합니다.
3. 중고 노트북 점검이라면 마모율과 사이클을 함께 기록합니다. 마모율만 보면 교체 배터리인지 구분하기 어렵습니다.

## 주의

일부 배터리는 설계 용량이나 사이클 정보를 보고하지 않습니다. 값이 0이나 공백으로 나오면 도구 오류가 아니라 배터리 펌웨어가 그 값을 제공하지 않는 것입니다. 데스크톱에서는 표시할 배터리가 없습니다.

```powershell
.\scripts\Open-PortableTool.ps1 -Root . -Id batteryinfoview -Language ko
```

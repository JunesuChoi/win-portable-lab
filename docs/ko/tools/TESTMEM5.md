# TestMem5 (TM5) 상세 사용법

RAM 오버클럭에서 서브타이밍이 잘못됐을 때 나타나는 오류를 짧은 시간에 찾아내는 도구입니다. y-cruncher와 Prime95가 통과해도 TM5에서 걸리는 경우가 흔합니다. 반대로 TM5가 통과했다고 완전한 안정성이 보장되지는 않습니다.

실행 ID는 `testmem5`이고 위험도는 고부하입니다. 관리자 권한이 필요합니다.

## 실행 전 확인

1. HWiNFO를 먼저 띄워 메모리와 VRM 온도, CPU 온도를 볼 수 있게 합니다.
2. 저장하지 않은 작업을 모두 닫습니다. 메모리 오류가 발생하면 프로그램이 비정상 종료될 수 있습니다.
3. 백신 예외를 준비합니다. TM5는 저수준 메모리 접근 때문에 오탐이 자주 발생합니다. 격리되면 실행 자체가 실패합니다.

## 프로필 선택

TM5 0.13.1에는 프로필이 `bin` 폴더에 포함되어 있습니다. 별도로 받을 필요가 없습니다.

| 프로필 파일 | 성격 | 권장 상황 |
|---|---|---|
| `Extreme @ anta777.cfg` | 표준 검증. 가장 널리 쓰이는 기준 | 처음 검증할 때 기본 선택 |
| `Absolut @ anta777.cfg` | Extreme보다 강한 부하 | Extreme 통과 후 추가 확인 |
| `DDR5 Intel @ anta777.cfg` | DDR5 인텔 플랫폼 전용 | DDR5 + 인텔 조합 |
| `DDR5 Ryzen3D @ anta777.cfg` | DDR5 라이젠 X3D 전용 | DDR5 + X3D 조합 |
| `Heavy @ anta777.cfg` | 무거운 패턴 위주 | 특정 패턴에서만 나는 오류 추적 |
| `Super Light 2 @ anta777.cfg` | 매우 짧은 확인 | 값을 바꿔가며 빠르게 걸러낼 때 |
| `1usmus v3 @ 1usmus.cfg` | 라이젠 초기 세대용 고전 프로필 | 구형 라이젠 |
| `Default @ serj.cfg` | 제작자 기본값 | 참고용 |

플랫폼에 맞는 전용 프로필이 있으면 그것을 우선합니다. DDR4라면 `Extreme @ anta777.cfg`가 기본입니다.

## 프로필 적용 절차

이 순서를 지키지 않으면 이전 프로필로 검사됩니다.

1. TM5를 관리자 권한으로 실행합니다.
2. 프로필을 선택하고 `Load config & exit`를 누릅니다. 프로그램이 종료됩니다.
3. TM5를 다시 관리자 권한으로 실행합니다.
4. 메인 화면 상단에 표시되는 프로필 이름이 의도한 것인지 확인합니다. 예를 들어 Extreme을 골랐다면 `Extreme1 / anta777`로 표시됩니다.
5. `Run` 또는 시작 버튼으로 검사를 시작합니다.

## 화면 해석

- `Cycle`: 전체 검사 주기입니다. Extreme 프로필은 1사이클에 보통 20분에서 40분이 걸립니다. 시스템 속도와 용량에 따라 달라집니다.
- `Test`: 현재 실행 중인 패턴 번호입니다. 특정 번호에서 반복해 오류가 나면 관련 타이밍을 좁힐 단서가 됩니다.
- `Errors`: 반드시 0이어야 합니다. 1 이상이면 그 설정은 불안정합니다.
- `Coverage`: 검사한 메모리 범위입니다.

## 판정 기준

| 목적 | 권장 실행량 | 통과 조건 |
|---|---|---|
| 값을 바꿔가며 빠르게 걸러내기 | Super Light 2로 1사이클 | 오류 0 |
| 기본 검증 | Extreme 1사이클 | 오류 0 |
| 상용 안정성 | Extreme 3사이클 이상 | 전 구간 오류 0 |
| 최종 확인 | Absolut 1사이클 추가 | 오류 0 |

오류가 1개라도 나오면 통과가 아닙니다. 전압을 올리거나 타이밍을 완화하거나 클럭을 낮춘 뒤 처음부터 다시 검사합니다.

## 즉시 중단 조건

- 메모리 또는 VRM 온도가 제조사 한계에 접근할 때
- 오류가 발생했을 때. 계속 돌려도 정보가 늘지 않고 데이터 손상 위험만 커집니다.
- 시스템이 멈추거나 재부팅될 때. 이 경우도 불안정으로 판정합니다.
- 이벤트 로그에 WHEA 오류가 기록될 때

## 다른 도구와의 관계

TM5는 메모리 오류 검출에 특화되어 있습니다. CPU 코어 안정성은 Prime95, 복합 부하는 OCCT, 운영체제 영향을 배제한 검사는 MemTest86+로 확인합니다. TM5 통과 후 HCI MemTest로 커버리지를 누적하면 신뢰도가 올라갑니다.

```powershell
.\scripts\Open-PortableTool.ps1 -Root . -Id testmem5 -AcknowledgeRisk -Language ko
```

# OCCT 상세 사용법

CPU, 메모리, 전원, 그래픽을 함께 부하 주면서 오류를 검출합니다. Prime95가 계산 안정성에 집중한다면 OCCT는 전원 공급과 복합 부하에서 드러나는 문제를 봅니다. 이 프로젝트에서 가장 부하가 큰 도구입니다.

실행 ID는 `occt`이고 위험도는 매우 높은 부하입니다.

## 실행 전 확인

1. HWiNFO로 CPU 온도, VRM 온도, 12V 레일, 전력을 감시할 준비를 합니다.
2. 저장하지 않은 작업을 모두 닫습니다.
3. 전원 공급 장치 용량과 사용 기간을 확인합니다. 노후 파워는 이 검사에서 보호 회로가 작동할 수 있습니다.
4. 케이스 흡배기가 막혀 있지 않은지 확인합니다.

## 테스트 종류

| 종류 | 부하 대상 | 권장 상황 |
|---|---|---|
| CPU | CPU 연산 | 코어 안정성 확인 |
| Memory | 메모리 영역 | RAM 검증 보조 |
| 3D Standard | GPU | 그래픽 단독 부하 |
| 3D Adaptive | GPU 가변 부하 | 전원 변동 대응 확인 |
| Power | CPU와 GPU 동시 최대 | 전원 공급 한계 확인. 가장 위험 |

`Power` 테스트는 전원 공급 장치를 한계까지 밀어붙입니다. 파워 상태가 의심되면 실행하지 않습니다. 시스템이 즉시 꺼질 수 있습니다.

## 주요 설정

| 설정 | 의미 | 권장 |
|---|---|---|
| Test Mode | 데이터셋 크기와 부하 방식 | 처음에는 기본값 |
| Instruction Set | AVX, AVX2, SSE 선택 | 실사용 기준이면 AVX2까지 |
| Duration | 검사 시간 | 짧게 시작해 늘림 |
| Error Behavior | 오류 시 동작 | 오류 발생 시 중단으로 설정 |
| Monitoring 임계값 | 온도 상한 지정 | 모델 공식 한계보다 낮게 설정 |

OCCT는 자체 감시 기능으로 지정 온도 초과 시 자동 중단할 수 있습니다. 이 값을 반드시 설정합니다. 무인 실행 시 유일한 안전장치입니다.

## 판정 기준

| 목적 | 권장 시간 | 통과 조건 |
|---|---|---|
| 빠른 선별 | CPU 10분 | 오류 0 |
| 기본 검증 | CPU 30분 + Memory 30분 | 오류 0 |
| 상용 안정성 | 각 60분 | 오류 0, 온도 안정 |
| 전원 한계 확인 | Power 10분 | 오류 0, 재부팅 없음 |

OCCT는 오류를 감지하면 화면에 표시하고 로그에 남깁니다. 오류가 1개라도 나오면 통과가 아닙니다.

## 즉시 중단 조건

- CPU 또는 GPU 온도가 모델 공식 한계에 접근할 때
- 12V 레일 전압이 규격 범위를 벗어날 때
- 시스템이 갑자기 꺼질 때. 전원 공급 문제 신호입니다.
- 오류가 표시될 때
- 이벤트 로그에 WHEA 오류가 기록될 때

갑작스러운 전원 차단은 파워 또는 전원 회로 문제를 의미합니다. 이 경우 부하 검사를 반복하지 말고 전원 계통을 먼저 점검합니다.

## 다른 도구와의 관계

OCCT는 복합 부하와 전원 검증에 강합니다. 계산 안정성 단독 확인은 Prime95, 메모리 오류 정밀 검출은 TestMem5가 낫습니다. 순서는 Prime95와 TestMem5로 각 축을 확인한 뒤 OCCT로 종합하는 편이 원인 분리에 유리합니다.

```powershell
.\scripts\Open-PortableTool.ps1 -Root . -Id occt -AcknowledgeRisk -Language ko
```

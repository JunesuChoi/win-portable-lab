# Ventoy 상세 사용법

USB 하나에 ISO 파일을 그대로 복사해 두고 부팅 시 골라 실행하는 도구입니다. 이 프로젝트에서는 MemTest86+처럼 Windows 밖에서 실행해야 하는 검사 매체를 만드는 데 씁니다.

실행 ID는 `ventoy`이고 위험도는 시스템 변경입니다. USB 장치를 초기화하므로 자동 실행하지 않습니다.

## 가장 중요한 경고

Ventoy 설치는 대상 USB 장치를 완전히 지웁니다. 실행 전에 반드시 확인합니다.

1. 목록에 표시된 장치가 의도한 USB인지 드라이브 문자와 용량으로 두 번 확인합니다.
2. 외장 하드나 백업 드라이브가 선택되지 않았는지 확인합니다.
3. USB에 남길 데이터가 없는지 확인합니다.

장치를 잘못 고르면 복구가 어렵습니다. 확인 전에는 `Install`을 누르지 않습니다.

## 설치 순서

1. USB를 연결합니다. 8GB 이상을 권장합니다.
2. Ventoy2Disk를 관리자 권한으로 실행합니다.
3. `Device` 목록에서 대상 USB를 고릅니다. 용량으로 재확인합니다.
4. 필요하면 `Option` 메뉴에서 파티션 방식을 정합니다. 기본값으로 두면 대부분 동작합니다.
5. `Install`을 누릅니다. 경고가 두 번 나오며 둘 다 확인해야 진행됩니다.
6. 완료 후 USB에 생긴 파티션에 ISO 파일을 그대로 복사합니다.

## 주요 옵션

| 옵션 | 의미 | 권장 |
|---|---|---|
| Partition Style MBR | 구형 BIOS와 폭넓은 호환 | 여러 기기를 오가는 점검용에 적합 |
| Partition Style GPT | UEFI 전용 최신 방식 | 최신 기기만 다룰 때 |
| Secure Boot Support | 보안 부팅 환경에서 부팅 허용 | 보안 부팅을 끄지 않으려면 활성화 |
| Preserve space | 끝부분 공간을 남김 | 특수 용도 외에는 불필요 |

현장 점검용으로 여러 기기를 오간다면 MBR과 보안 부팅 지원을 함께 쓰는 편이 호환성이 좋습니다.

## MemTest86+ 매체 만들기

1. 위 순서로 Ventoy를 설치합니다.
2. `tools/04-CPU-Memory-Stability/memtest86plus` 폴더의 ISO를 USB에 복사합니다.
3. 대상 PC에서 USB로 부팅합니다. 부팅 순서 변경이 필요할 수 있습니다.
4. Ventoy 메뉴에서 MemTest86+를 선택합니다.

보안 부팅이 켜져 있고 부팅이 막히면, 보안 부팅 지원 옵션으로 다시 설치하거나 해당 기기에서 일시적으로 보안 부팅을 끕니다. 점검이 끝나면 원래 설정으로 되돌립니다.

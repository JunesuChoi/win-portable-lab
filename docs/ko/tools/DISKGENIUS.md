# DiskGenius 상세 사용법

파티션 관리에 MBR/GPT 복구, 배드섹터 정밀 검사, 디스크 클론까지 갖춘 고급 도구입니다. 무료 등급으로 검사와 파티션 작업이 가능하고, 데이터 복구 결과를 저장하는 기능만 유료입니다. 강력한 만큼 실수 여지도 크므로 고급 보조로만 씁니다.

실행 ID는 `diskgenius`이고 위험도는 파티션 쓰기(최상위)입니다.

## 가장 중요한 원칙

**검사와 수정을 분리하십시오.** 검사는 읽기 전용이지만, 복구·복원·파티션 테이블 수정은 쓰기 작업입니다.

1. 검증되지 않은 PartitionGuru 포터블 같은 재배포본을 쓰지 않습니다. 이 프로젝트는 공식 사이트의 벤더 서명 ZIP만 기록합니다.
2. 복구·복원 작업 전 대상 디스크 전체를 백업하거나, 최소한 복제본을 만듭니다.
3. 프로그램이 제안하는 자동 복구를 바로 수락하지 말고, 대상 디스크 번호를 먼저 확인합니다.

## 주요 기능과 용도

| 기능 | 용도 | 무료 등급 |
|---|---|---|
| 파티션 생성·삭제·포맷·리사이즈 | 일반 파티션 관리 | 무료 |
| 배드섹터 검사 | 디스크 결함 정밀 확인, CrystalDiskInfo의 재할당 값보다 앞선 진단 | 무료 (복구 시도는 유료) |
| MBR/GPT 복구 | 부팅 불능·파티션 테이블 손상 시 | 무료 (저장 단계 주의) |
| 디스크/파티션 클론 | 교체 전 디스크 이주 | 무료 기능 있음 |
| 파일 복구 후 저장 | 삭제 파일 복원 | 유료 |

## 권장 절차 (배드섹터 검사)

1. 관리자 권한으로 실행합니다.
2. 왼쪽 디스크 목록에서 검사 대상을 선택합니다.
3. 메뉴에서 Bad Sectors - Verify Now를 실행합니다. 읽기 전용 검사입니다.
4. 결과가 전부 Normal이면 문제 없음입니다. Damaged/Critical이 늘면 그 디스크에 백업 의존을 멈춥니다.

## 절대 하지 말 것

이상 소음이나 재할당 섹터가 급증한 디스크에서 복구 시도를 반복하지 않습니다. 시도할수록 남은 데이터가 지워집니다. 먼저 백업·복제를 우선합니다.

## 다른 도구와의 관계

일상 파티션 작업은 Macrorit Partition Expert가 담당합니다. 배드섹터 검사 결과의 건강 추이는 CrystalDiskInfo와 smartmontools로 추적합니다. 파티션 작업 후 이벤트 로그 이상은 FullEventLogView로 확인합니다.

```powershell
.\scripts\Open-PortableTool.ps1 -Root . -Id diskgenius -AcknowledgeRisk -Language ko
```

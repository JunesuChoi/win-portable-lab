# H2testw 상세 사용법

빈 공간에 검증 가능한 패턴을 쓰고 다시 읽어 비교합니다. 표시 용량이 실제와 다른 가짜 USB나 SD 카드를 찾아내고, 저장장치가 데이터를 온전히 보관하는지 확인합니다. 속도 측정 도구가 아니라 무결성 확인 도구입니다.

실행 ID는 `h2testw`이고 위험도는 빈 공간 전체를 채우는 고위험 쓰기입니다.

## 실행 전 확인

1. 대상 드라이브에 중요한 데이터가 없는지 확인합니다.
2. 새로 포맷한 상태가 가장 정확합니다. 기존 파일이 있으면 남은 공간만 검사합니다.
3. USB라면 가능한 한 후면 단자에 직접 연결합니다. 허브를 거치면 오류가 연결 문제인지 장치 문제인지 구분이 어려워집니다.
4. 검사 시간을 예상합니다. 용량과 속도에 따라 수 시간이 걸립니다.

## 화면 설정

프로그램은 독일어와 영어를 지원합니다. 상단에서 English를 선택합니다.

| 설정 | 의미 | 권장 |
|---|---|---|
| Select target | 검사할 드라이브 | 대상 문자를 두 번 확인 |
| all available space | 남은 공간 전체 검사 | 정확한 검증에 권장 |
| only | 지정한 용량만 검사 | 시간이 부족할 때 |
| endless verify | 반복 검증 | 간헐적 오류 추적 |

`Write + Verify`가 기본 동작입니다. 이미 쓴 데이터를 다시 검증만 하려면 `Verify`를 씁니다.

## 결과 해석

검사가 끝나면 결과 문구가 나옵니다.

| 결과 | 의미 |
|---|---|
| `Test finished without errors` | 정상. 표시 용량과 무결성 모두 확인됨 |
| `The media is likely to be defective` | 불량. 데이터 손상 발생 |
| 쓴 용량이 표시 용량보다 크게 적음 | 가짜 용량. 컨트롤러가 용량을 속이는 중 |
| 특정 지점부터 오류 집중 | 해당 영역 낸드 불량 가능 |

오류가 1바이트라도 나오면 그 저장장치에 중요한 데이터를 두지 않습니다. 가짜 용량 USB는 일정 지점을 넘으면 이전 데이터를 덮어쓰기 때문에, 겉으로는 복사가 되는 듯 보이지만 나중에 파일이 깨집니다.

## 판정 기준

| 목적 | 권장 설정 | 통과 조건 |
|---|---|---|
| 신규 저장장치 검수 | all available space | 오류 0바이트 |
| 가짜 용량 의심 | all available space | 쓴 용량이 표시 용량과 일치 |
| 간헐적 오류 추적 | endless verify | 반복 중 오류 0 |
| 시간 부족한 빠른 확인 | only로 일부 지정 | 오류 0. 단 전체 보증은 아님 |

## 검사 후 정리

검사가 만든 `.h2w` 파일을 삭제합니다. 남겨두면 공간을 계속 차지합니다. 파일을 남기면 나중에 `Verify`로 재검증할 수 있으므로, 재검증 계획이 있으면 유지합니다.

## 다른 도구와의 관계

ValiDrive는 몇 분 안에 표시 용량을 스폿체크합니다. 빠른 선별에는 ValiDrive를 쓰고, 확정 판정에는 H2testw를 씁니다. 성능이 궁금하면 CrystalDiskMark가 목적에 맞습니다. SSD 지속 쓰기 특성은 나래온 더티 테스트가 담당합니다.

```powershell
.\scripts\Open-PortableTool.ps1 -Root . -Id h2testw -AcknowledgeRisk -Language ko
```

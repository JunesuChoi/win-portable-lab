# Snappy Driver Installer Origin (SDIO) 상세 사용법

설치된 드라이버를 검사해 누락되거나 오래된 항목을 찾아냅니다. 인터넷이 없는 현장에서도 드라이버팩을 미리 받아두면 동작하는 것이 이 도구의 핵심입니다. 재설치 직후 장치 관리자에 물음표가 남았을 때 씁니다.

실행 ID는 `sdio`이고 위험도는 시스템 변경과 재부팅입니다.

## 가장 중요한 원칙

**검사와 설치를 분리하세요.** 검사는 읽기 전용이라 안전하지만, 설치는 드라이버를 교체하므로 되돌리기가 번거롭습니다.

1. 설치 전 시스템 복원 지점을 만듭니다. 이 도구가 제공하는 복원 지점 생성 옵션을 켜두는 편이 안전합니다.
2. 노트북이라면 제조사 드라이버를 범용 드라이버로 덮어쓰지 않도록 주의합니다. 밝기 조절, 외부 출력, 전원 관리가 깨질 수 있습니다.
3. 그래픽 드라이버는 이 도구로 갱신하지 말고 제조사 정식 드라이버를 직접 설치하는 편이 안정적입니다.

## 드라이버팩 준비

프로그램 본체만으로는 설치할 드라이버가 없습니다. 드라이버팩을 별도로 받아야 합니다.

| 방식 | 용량 | 적합한 경우 |
|---|---|---|
| 전체 드라이버팩 | 수십 GB | 오프라인 현장에서 여러 기종을 다룰 때 |
| 필요한 팩만 선택 | 수 GB | 특정 장치만 해결할 때 |
| 인덱스만 받고 온라인 설치 | 작음 | 인터넷이 되는 환경 |

이 프로젝트는 드라이버팩을 포함하지 않습니다. 용량이 매우 크고 갱신이 잦기 때문입니다. 필요하면 도구 안에서 직접 받습니다.

## 화면 해석

| 표시 | 의미 |
|---|---|
| 초록 | 현재 드라이버가 최신이거나 적절함 |
| 파랑 | 더 새로운 드라이버가 있음 |
| 노랑 | 권장되지만 신중히 판단할 항목 |
| 빨강 | 드라이버가 없거나 문제 있음 |
| Expert mode | 개별 드라이버 버전을 직접 선택 |

빨강 항목이 실제 문제입니다. 파랑은 굳이 갱신하지 않아도 되는 경우가 많습니다. 잘 동작하는 드라이버를 최신으로 바꿨다가 문제가 생기는 사례가 흔합니다.

## 권장 절차

1. 관리자 권한으로 실행합니다.
2. 드라이버팩 또는 인덱스를 받습니다.
3. 검사 결과를 확인만 합니다. 이 단계까지는 시스템을 바꾸지 않습니다.
4. 빨강으로 표시된 누락 드라이버만 선택합니다.
5. 복원 지점 생성 옵션을 확인하고 설치합니다.
6. 재부팅 후 장치 관리자에서 문제 표시가 사라졌는지 확인합니다.

## 절대 사용하지 말 것

패키지에 포함된 `SDIO_auto.bat`은 사용자 확인 없이 드라이버를 일괄 설치합니다. 이 프로젝트는 자동 실행을 금지하므로 이 배치 파일을 쓰지 않습니다. 무엇이 바뀌는지 모르는 상태에서 드라이버가 교체되면 원인 추적이 불가능해집니다.

## 다른 도구와의 관계

드라이버 저장소에 쌓인 중복 패키지 정리는 DriverStore Explorer가 담당합니다. 그래픽 드라이버 완전 제거는 DDU를 씁니다. 드라이버가 성능 문제의 원인인지 판단하려면 LatencyMon으로 근거를 먼저 확보합니다. SDIO는 "없는 드라이버를 찾아 채우는" 역할에 한정해 쓰는 편이 안전합니다.

```powershell
.\scripts\Open-PortableTool.ps1 -Root . -Id sdio -AcknowledgeRisk -Language ko
```

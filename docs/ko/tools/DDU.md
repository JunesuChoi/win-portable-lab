# DDU (Display Driver Uninstaller) 상세 사용법

그래픽 드라이버를 레지스트리와 잔여 파일까지 완전히 제거합니다. 일반적인 제거로 해결되지 않는 문제에만 씁니다. 정상 동작하는 시스템에 예방 목적으로 실행할 도구가 아닙니다.

실행 ID는 `ddu`이고 위험도는 시스템 변경과 재부팅입니다.

## 언제 쓰는가

| 상황 | DDU 필요 |
|---|---|
| NVIDIA에서 AMD로, 또는 반대로 교체 | 필요 |
| 드라이버 설치가 반복 실패 | 필요 |
| 화면 깨짐, 검은 화면이 드라이버 재설치로 해결 안 됨 | 필요 |
| 드라이버 버전만 올리기 | 불필요. 일반 설치로 충분 |
| 문제 없는데 정기 청소 | 불필요 |

## 실행 전 반드시 준비

1. 설치할 드라이버 파일을 미리 다운로드해 둡니다. DDU 실행 후에는 화면 해상도가 기본값이 되고 네트워크 드라이버가 영향을 받는 경우도 있습니다.
2. 현재 드라이버 버전을 기록합니다. 되돌릴 필요가 생길 수 있습니다.
3. 노트북이면 제조사 전용 드라이버인지 확인합니다. 범용 드라이버로 교체하면 밝기 조절이나 외부 출력이 동작하지 않을 수 있습니다.
4. 안전 모드 실행을 권장합니다. DDU가 안전 모드 재부팅을 도와줍니다.

## 주요 옵션

| 옵션 | 의미 | 권장 |
|---|---|---|
| Device type 선택 | GPU, 오디오, 네트워크 | 그래픽 문제면 GPU만 |
| 제조사 선택 | NVIDIA, AMD, Intel | 현재 설치된 것 |
| Clean and restart | 제거 후 자동 재부팅 | 기본 권장 |
| Clean and shutdown | 제거 후 종료 | 카드를 물리적으로 교체할 때 |
| Clean, no restart | 제거만 | 연속 작업이 필요할 때만 |
| Windows Update 드라이버 자동 설치 방지 | 임시로 자동 설치 차단 | 원하는 버전을 직접 넣을 때 활성화 |
| C:\AMD, C:\NVIDIA 폴더 삭제 | 설치 잔여 폴더 제거 | 활성화 |

`Clean and shutdown`은 그래픽 카드를 실제로 교체할 때 씁니다. 드라이버를 지운 상태로 종료하므로 카드를 바꿔 끼운 뒤 새로 설치하면 됩니다.

## 실행 순서

1. 새 드라이버 파일을 미리 받아둡니다.
2. DDU를 실행하고 장치 종류와 제조사를 고릅니다.
3. Windows Update 자동 설치 방지를 켭니다.
4. `Clean and restart`를 누릅니다.
5. 재부팅 후 낮은 해상도로 시작합니다. 정상입니다.
6. 미리 받아둔 드라이버를 설치합니다.
7. 설치 후 GPU-Z로 드라이버 버전과 인식 상태를 확인합니다.
8. Windows Update 자동 설치 방지를 원래대로 되돌립니다.

5단계에서 화면이 아예 나오지 않으면 메인보드 내장 출력 단자를 시도합니다.

## 주의

- Windows Update 차단을 켠 채로 방치하지 않습니다. 다른 드라이버 갱신도 막힙니다.
- 네트워크 드라이버까지 제거하면 인터넷이 끊겨 드라이버를 받을 수 없습니다. 그래픽 문제라면 GPU만 선택합니다.
- 노트북에서 제조사 드라이버를 범용으로 바꾸면 기능이 줄어들 수 있습니다.

## 다른 도구와의 관계

드라이버 저장소에 쌓인 중복 패키지 정리는 DriverStore Explorer가 담당합니다. 드라이버가 원인인지 판단하는 단계에서는 LatencyMon과 FullEventLogView로 근거를 먼저 확보합니다. DDU는 원인이 드라이버로 좁혀진 뒤 마지막에 쓰는 도구입니다.

```powershell
.\scripts\Open-PortableTool.ps1 -Root . -Id ddu -AcknowledgeRisk -Language ko
```

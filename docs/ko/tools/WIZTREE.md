# WizTree 상세 사용법

디스크 공간이 어디에 쓰였는지 빠르게 보여줍니다. NTFS의 마스터 파일 테이블을 직접 읽기 때문에 폴더를 하나씩 훑는 방식보다 훨씬 빠릅니다. 이 프로젝트에서는 쓰기 테스트 전에 빈 공간이 충분한지 판단하는 용도로 씁니다.

실행 ID는 `wiztree`이고 읽기 전용입니다. MFT 직접 접근 때문에 관리자 권한이 필요합니다.

## 이 프로젝트에서의 용도

H2testw와 나래온 더티 테스트는 빈 공간을 채웁니다. 실행 전에 다음을 확인합니다.

1. 대상 드라이브의 실제 빈 공간이 예상과 맞는지
2. 지워도 되는 대용량 임시 파일이 남아 있는지
3. 이전 테스트가 남긴 테스트 파일이 있는지

## 화면 해석

| 요소 | 의미 |
|---|---|
| 트리 목록 | 폴더별 크기를 큰 순서로 정렬 |
| 크기 막대 | 상위 폴더 대비 비중 |
| 트리맵 | 파일 크기를 사각형 면적으로 표현 |
| Allocated 열 | 디스크에 실제 할당된 크기 |
| Files 열 | 하위 파일 개수 |

실제 파일 크기와 할당 크기가 다를 수 있습니다. 작은 파일이 많으면 할당 크기가 더 큽니다. 빈 공간 판단에는 할당 크기가 기준입니다.

## 사용 순서

1. 상단에서 검사할 드라이브를 고르고 `Scan`을 누릅니다.
2. 크기 순으로 정렬된 상위 폴더를 확인합니다.
3. 파일 유형별 집계는 `File View` 탭에서 확인합니다.
4. 필요하면 `Export`로 목록을 CSV로 저장합니다.

## 주의

WizTree에는 삭제 기능이 있습니다. 이 프로젝트는 공간 확인 목적으로만 사용하며, 삭제는 자동화하지 않습니다. 시스템 폴더의 대용량 파일을 임의로 지우면 Windows가 손상될 수 있습니다. 지워도 되는지 확실하지 않으면 지우지 않습니다.

비상업적 사용은 무료입니다. 업무용은 라이선스가 필요합니다.

```powershell
.\scripts\Open-PortableTool.ps1 -Root . -Id wiztree -Language ko
```

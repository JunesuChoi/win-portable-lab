# RAM 오버클럭과 안정화

XMP와 EXPO도 오버클럭입니다. 메모리 키트의 표기 속도가 모든 CPU 메모리 컨트롤러·보드·BIOS·DIMM 구성에서 보장되는 것은 아닙니다.

## 순서

1. CPU와 RAM을 기본값으로 설정합니다.
2. 보드 설명서의 권장 슬롯을 사용합니다.
3. JEDEC에서 콜드 부팅과 10분 스모크를 통과합니다.
4. CPU 기본 안정성을 먼저 확인합니다.
5. XMP/EXPO Profile 1만 켜고 다른 값은 바꾸지 않습니다.
6. 훈련을 기다린 뒤 실제 적용 속도·타이밍을 확인합니다.
7. 10분 스모크, 60분 다중 패턴, 부팅형 4패스, 콜드 부팅 3회를 진행합니다.

## 플랫폼 기록값

- Intel DDR4/DDR5: XMP 버전, Gear/컨트롤러 모드, DIMM 수와 용량
- AMD AM4: MCLK/UCLK/FCLK
- AMD AM5: EXPO 프로필, MCLK/UCLK/FCLK, 메모리 훈련과 절전 복귀
- 공통: 파트 번호, 슬롯, 총 용량, 현재 속도, 주요 타이밍, CPU 튜닝 상태

오류 허용치는 0개입니다. 오류가 하나라도 발생하면 전압을 연속해서 더하지 말고 마지막 통과 설정으로 돌아갑니다. 서로 다른 키트 혼용은 같은 검증 키트로 보지 않습니다.
